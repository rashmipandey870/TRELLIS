# TRELLIS Enterprise Executive Summary
**CSM Technology Learning & Knowledge (L&K) Governance Platform**

---

## 1. Executive Overview
**TRELLIS** is an enterprise-grade learning, assessment, and talent development platform built for CSM Technology's engineering workforce. Designed around the metaphor of a trellis supporting growing tendrils, the platform supports engineering progression through continuous coding practice, scheduled assessments, qualitative mentor guidance, and automated talent discovery.

### Key Metrics & Capacities
- **Users**: 42 seeded enterprise accounts (1 Admin Governance Officer, 5 Mentors, 36 Learners across 4 batches).
- **Curriculum Breadth**: 353 vetted questions across 7 enterprise categories plus situational judgement.
- **Coding Lab**: 24 LeetCode-style problems across 5 programming languages (Python, SQL, Java, JavaScript, C++) with an automated judge harness, typed argument schemas, and custom test runners.
- **Assessments**: 12 formal multi-format assessments covering the entire lifecycle (Draft, Scheduled, Published, Closed).
- **Evaluation Records**: 164 bell-curve graded assessment attempts, 468 evaluated code submissions, and 900+ AI practice drills.

## 2. Architectural Pillars

### 2.1 Credibility & Honest AI
- **No Mock or Hardcoded Data**: All endpoints query real database tables; empty sets render clean, informative empty states in the UI.
- **Truthful AI Provenance**: Every question, drill, and suggestion explicitly reports its provenance (`provider`, `model`, `prompt_version`, `served_from`). Procedural drills are badged as `"Practice bank"`; only verified generative outputs carry the `"Generated by TRELLIS AI"` badge.
- **Offline Resilience**: When AI models are offline, the system never invents fake responses; it displays an honest structured data card derived from backend database metrics.

### 2.2 Security & Compliance (DPDP Act Ready)
- **Zero Secret Fallbacks**: Fails fast if cryptographic keys (`SECRET_KEY`, `FIELD_ENCRYPTION_KEY`, `LEDGER_SALT_KEY`) are missing.
- **Enterprise Security Headers**: Strict Content Security Policy (CSP), HSTS, `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, and Referrer-Policy.
- **Immutable Evidence Ledger**: RFC 8785 canonical JSON serialization with SHA-256 hash chaining to ensure tamper-evident audit trails.
- **DPDP Section 6 & 11 Consent Passports**: 1-click purpose-specific consent capture and cryptographic revocation.

### 2.3 User Experience & CSM Design Language
- **Tri-Colour Spectrum**: Saffron (`#FAA634`), Signal Red (`#D7182A`), and Cerulean (`#008FBB`) with high-contrast text tokens meeting WCAG AA standards.
- **Design Signatures**: Cut-corner cards with dynamic tone rails, slanted-bar motifs (`-21.7deg`), and tabular numerals for scores and timers.
- **Keyboard Navigation**: Application-wide Command Palette accessible via `Ctrl+K` / `Cmd+K`.
- **Accessibility**: Full keyboard navigation, skip-to-content links, live screen-reader regions, and prefers-reduced-motion overrides.
